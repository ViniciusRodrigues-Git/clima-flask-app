# 🌤️ App de Consulta de Clima

Um aplicativo web moderno desenvolvido com **Flask** que consome a API do OpenWeather para exibir condições climáticas em tempo real com um design inspirado em *Glassmorphism*.

## 🚀 Tecnologias
* Python
* Flask
* HTML5/CSS3 (Customizado)
* API OpenWeather

## 🎨 Layout
O design foi focado em uma interface limpa, utilizando efeitos de desfoque (blur) e gradientes suaves para uma experiência de usuário moderna.

## 🛠️ Como rodar o projeto
1. Clone o repositório:
   `git clone https://github.com/ViniciusRodrigues-Git/clima-flask-app.git`
2. Instale as dependências:
   `pip install -r requirements.txt`
3. Execute o app:
   `python app.py`
